# Tavrix Menu Admin Web

Internal Next.js App Router dashboard for Tavrix Menu service owners.

This app is not for restaurant or cafe owners. Business owners, managers, and staff use the Flutter app.

## Run

From the repository root:

```bash
pnpm dev:admin
```

Open:

```text
http://localhost:3002
```

## Environment

Copy `.env.example` to `.env`.

Clerk placeholders are present now. Real Clerk route protection and backend admin checks will be added later.
