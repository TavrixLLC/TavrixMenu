# Waflo Design Documentation Instructions

Inherit all repository instructions from the root `AGENTS.md`.

- Design documentation and approved PNGs are references and contracts.
- Never alter approved PNG bytes without explicit human approval.
- Do not crop screenshot assets into production assets.
- Do not copy Btaqa or Stitch assets, code, branding, text, or proprietary
  visual composition.
- An approved visual never overrides security, accessibility, responsive
  behavior, or truthful backend state.
- Follow the exact screen authority chain documented in
  `docs/design/stitch/waflo-mobile-redesign/`.
- Codex may report implementation mismatches but cannot approve the visual
  implementation or claim `HUMAN_VISUAL_PASS`.
- Do not fabricate a future visual or create a placeholder "approved" PNG.
