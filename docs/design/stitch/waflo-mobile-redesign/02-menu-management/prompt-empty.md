# Menu Management — Approved Empty-State Direction

## Visual authority

Use [empty-approved.png](empty-approved.png) as the visual reference for the exact `EMPTY_ONE_CATEGORY` state. Preserve its Arabic-first RTL hierarchy, clear menu-readiness summary, category-first organization, prominent first-product action, fully muted customer preview, and equal five-tab bottom navigation.

The raster is not a production asset and does not define fixed coordinates, a fixed page height, or implementation code.

## Exact scenario

- The authoritative active business has exactly one real category named `المقبلات`.
- The selected category has zero products.
- Do not show fake product cards, prices, availability, or thumbnails.
- Customer preview is disabled because no real public product is available.
- `إضافة أول منتج` is the clear primary action.
- Category modification remains secondary.

## Honesty constraints

- Category and product records must come from the authoritative active business.
- Never invent a category to make the screen resemble the raster.
- Never turn a failed load into a zero-product empty state.
- Never enable customer preview without a real public route and real menu readiness.
- Never simulate category or product mutation success.
- If a visible feature is unwired, keep it disabled or informational with an explanation.
