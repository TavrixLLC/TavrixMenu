# Stripe Plans

For the detailed billing guide, see [11-stripe-billing.md](11-stripe-billing.md).

Stripe billing is planned for monthly and yearly Tavrix Menu subscriptions. Actual Stripe product IDs and price IDs will be configured later.

## Tavrix Menu Basic

- QR Menu
- 100 menu items
- 1 branch
- 3 staff users
- basic analytics
- no custom domain initially
- no wallet integration initially
- no advanced loyalty initially

Pricing placeholders:

- Basic monthly: 19 USD
- Basic yearly: 190 USD

## Tavrix Menu Pro

- 500 menu items
- 5 branches
- 15 staff users
- AI suggestions
- loyalty features later
- custom domain later
- wallet integration later
- advanced analytics later

Pricing placeholders:

- Pro monthly: 49 USD
- Pro yearly: 490 USD
