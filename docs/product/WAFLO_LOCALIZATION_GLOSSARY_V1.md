# Waflo Localization Glossary V1

This glossary defines the intended product meaning of common Waflo terms. It
does not translate restaurant names, category names, product names, customer
names, or other merchant-entered content. `Waflo` remains the brand name in
every language.

Sorani Kurdish wording is an implementation draft and requires human language
review before release acceptance.

## Usage Rules

- Keep operational actions short and direct.
- Do not translate or transliterate the `Waflo` brand.
- Keep `IQD`, `Apple Wallet`, `Google Wallet`, `QR`, and validated URLs
  direction-safe when they appear inside RTL sentences.
- Unsupported capabilities must remain disabled or informational in every
  locale.
- Human review must validate Sorani grammar, terminology, and regional tone
  before the language is accepted for production.
